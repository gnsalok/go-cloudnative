# Certificate Output Files (`docs/certs/out`)

This file explains every artifact generated by:

```bash
./docs/certs/generate-local-certs.sh
```

## Quick classification

- Private keys (secret): any `*.key`
- Public certificates (shareable): any `*.crt`
- Signing requests (temporary): any `*.csr`
- OpenSSL extension configs (build-time): `*-ext.cnf`
- CA serial trackers (build-time): `*.srl`

## File-by-file map

| File | Type | Private/Public | Used by | Why it exists |
|---|---|---|---|---|
| `server.key` | Server private key | Private | Ingress secret (`go-app-tls`/`go-app-mtls`) | Proves server identity for gateway TLS handshake |
| `server.crt` | Server certificate | Public | Ingress secret (`go-app-tls`/`go-app-mtls`) | Certificate presented by ingress for `example.com` |
| `server-ca.key` | Server CA private key | Private | Local signing only | Signs `server.crt` |
| `server-ca.crt` | Server CA certificate | Public | Client trust (`curl --cacert`) | Lets client trust `server.crt` |
| `server.csr` | Server CSR | Public-ish temp artifact | Local signing only | Input request used to create `server.crt` |
| `server-ext.cnf` | OpenSSL ext config | Public | Local signing only | Adds SAN + `serverAuth` extension |
| `server-ca.srl` | OpenSSL CA serial file | Public-ish temp artifact | Local signing only | Tracks cert serial numbers issued by `server-ca` |
| `client.key` | Client private key | Private | External client (`curl --key`) | Proves client identity in north-south mTLS |
| `client.crt` | Client certificate | Public | External client (`curl --cert`) | Client cert presented to ingress when mode is `MUTUAL` |
| `client-ca.key` | Client CA private key | Private | Local signing only | Signs `client.crt` |
| `client-ca.crt` | Client CA certificate | Public | Ingress mTLS trust (`go-app-mtls` as `ca.crt`) | Ingress uses this CA to validate client certs |
| `client.csr` | Client CSR | Public-ish temp artifact | Local signing only | Input request used to create `client.crt` |
| `client-ext.cnf` | OpenSSL ext config | Public | Local signing only | Adds `clientAuth` extension |
| `client-ca.srl` | OpenSSL CA serial file | Public-ish temp artifact | Local signing only | Tracks cert serial numbers issued by `client-ca` |

## Which files are private keys?

These are private keys and must be protected:

- `docs/certs/out/server.key`
- `docs/certs/out/client.key`
- `docs/certs/out/server-ca.key`
- `docs/certs/out/client-ca.key`

## Which files go into Kubernetes secrets?

SIMPLE TLS (`credentialName: go-app-tls`):

- `tls.crt` <- `server.crt`
- `tls.key` <- `server.key`

MUTUAL TLS (`credentialName: go-app-mtls`):

- `tls.crt` <- `server.crt`
- `tls.key` <- `server.key`
- `ca.crt` <- `client-ca.crt`

## Which files are used by curl client?

Server trust and mTLS auth from local machine:

- `--cacert docs/certs/out/server-ca.crt`
- `--cert docs/certs/out/client.crt` (only for MUTUAL test)
- `--key docs/certs/out/client.key` (only for MUTUAL test)

## Safety note

- Do not commit `*.key` files to Git.
- If a private key is exposed, regenerate all certs:

```bash
rm -rf docs/certs/out
./docs/certs/generate-local-certs.sh
```
